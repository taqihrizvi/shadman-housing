└─────────────────────────────────────────────────────────────────────┘

  1. First time setup:
     .\setup-local.ps1

  2. Start backend (in separate terminal):
     cd ../backend
     npm run dev

  3. Start frontend:
     npm run dev:local

  4. Open browser:
     http://localhost:8080

  5. Check console for:
     🌍 Environment: local
     🔗 API URL: http://localhost:5000/api

     → Check backend is running
